* 프로젝트 폴더: [react-app](../react-app)

### Props VS State

* props
  * 읽기 전용
    * 컴포넌트 안에서 외부에서 전달받은 props의 값을 바꾸는 것은 금지됨
  * 수정될 수 없음
* state
  * 비동기 적으로 변경 될 수 있음
  * this.setState를 사용하여 변경 할 수 있음



### 지금까지 진행한 컴포넌트에 대해서...

* Apps 상위 컴포넌트 Subject, TOC, Content 하위 컴포넌트
* 상위 컴포넌트가 하위 컴포넌트로 값을 전달 할 때는 `props`로 전달
* 하위 컴포넌트가 상위 컴포넌트의 값을 바꾸고 싶을 때는 `이벤트`를 사용



### Redux

데이터를 각 컴포넌트에 분산해서 보관하지 않고, 하나의 데이터 저장소를 따로 두고, 데이터 저장소의 값이 바뀌면 해당 값과 관련된 모든 컴포넌트가 알아서 바뀌게 하는 기법
