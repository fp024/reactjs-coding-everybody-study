## 22. 수업을 마치며

* 동영상 강의: https://youtu.be/jukwa3_4LdI 

* 프로젝트 폴더: [react-app](../react-app)



### immutable

* 구현을 단순하게 유지해서 높은 복잡성에 도전하기위한 노력
* 배열 객체를 불변적으로 다루기 위한 라이브러리
  * [immutable.js](https://immutable-js.com/)

### router

* URL에 따라 다른 UI가 나오게 할 수 있음.
* React Router
  * https://github.com/remix-run/react-router
  * https://velog.io/@velopert/react-router-v6-tutorial



### Redux

* 중앙에 데이터 저장소를 하나 만들고, 모든 컴포넌트를 그 중앙 저장소와 직접 연결, 저장소의 데이터가 변경되면 그와 관련된 모든 컴포넌트가 영향을 받아서 변화함.



### react server side rendering

* 서버 측에서 리액트 랜더링



### React Native

* 리액트와 같은 방법으로 네이티브 앱을 만들 수 있음.
